Homepage Mail: Privacy Policy

Last updated: November 2026

What this app is

Homepage Mail is a personal, single-user tool that lets its owner see unread Gmail messages on their own private home dashboard. It is not offered to the public.

Data accessed

With the owner's permission, the app uses the Google gmail.readonly scope to read the unread count and the sender and subject headers of recent unread messages. It does not read message bodies or attachments, and it cannot send, modify or delete email.

How data is used and stored

The data is shown only on the owner's private dashboard, running on the owner's own server. It is held in memory for a few minutes and is not written to disk, sold, shared, or transferred to any third party. No advertising or analytics are used.

Google API Services User Data Policy

Homepage Mail's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
